## FINAL STATUS: **L10 = PARTIAL**

Persistence доказана (loop-learning → shared LayeredMemory → `_runtime_snapshot.json`
→ hard restart → restore → 35 episodes с retrieved Foundation-фактом восстановлены,

Causal behavior change НЕ доказан — **две структурные причины в LLM-free loop**:

1. **Episodes НЕ сворачиваются в plan.** `cognitive_kernel.py:541` гейтит инъекцию
   `past-experience` на `any(c.execution_steps for c in candidates)`. LLM-free loop
   генерирует plan `('explore:no-world-fact',)` без `execution_steps` → restored episode
   НЕ попадает в plan N+1. Plan N+1 идентичен control (оба `[]`/`explore:no-world-fact`).

2. **Keyword retrieval требует термин-оверлапа.** `_retrieve_similar_episodes` (406-423)
   в LLM-free kernel = `_retrieve_by_keyword` (нет embedding). Эпизод хранит node-id
   (`jurafsky_martin_speech_and_language_processing`), НЕ query-термин ("entropy").
   Чтобы извлечь эпизод в N+1, prompt должен содержать имя документа → нарушает
   ТЗ STEP 9 (no prompt-leak). Чистый "fact не в prompt" causal test структурно
   невозможен при keyword-only retrieval.

Механизм retrieval САМ работает (эпизоды восстанавливаются и доступны через
`appT.memory._episodes`), но не влияет на поведение N+1 из-за гейта execution_steps
и отсутствия semantic retrieval.
