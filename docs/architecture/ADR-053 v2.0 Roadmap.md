# ADR-053: KROFT_OS v2.0 Roadmap (TZ-015..023)

## 1. Context
Пользователь дал 9 ТЗ (TZ-015..023), описывающих эволюцию KROFT_OS от распределённой
системы до когнитивной ОС. Каждый ТЗ получил research-first design (ADR-044..052,
RFC-015..023). Этот ADR — сводка v2.0: как все слои складываются в финальную
архитектуру (снизу вверх).

## 2. Layer Stack (v2.0 target)
```
Identity Layer            (TZ-023 IIdentityLayer)
  │
Executive Function       (TZ-023 IExecutiveFunction + IConsciousWorkspace + IAttentionEngine)
  │
Autonomous Planner       (TZ-016 Goal→Task DAG→Execution)
  │
Multi-Agent Society      (TZ-019 Roles/Reputation/Negotiation/Voting/Auctions)
  │
Reflection Engine        (TZ-017 Memory Evolution + TZ-020 Self Improvement)
  │
World Simulation         (TZ-018 World Model: objects/relations/time/causality/probability)
  │
Distributed KG           (WP-14 CRDT Graph + TZ-022 Federated selective sharing)
  │
Federated Memory         (TZ-017 + TZ-022 selective sync)
  │
Distributed Runtime      (TZ-015: CRDT/EventBus/Raft-lite/Discovery/Registry/RemoteExec/SharedCtx/NetSupervisor/Metrics)
  │
Plugin Ecosystem         (TZ-021 Marketplace: registries/versioning/compat)
  │
Local / Cloud Models     (TZ-AGENT-001 ILlm)
```

## 3. Reuse Map (substrate)
- **WP-14** (ADR-043): CrdtGraphEngine, RaftLiteElector, TcpEventBus, SupervisorFailover
  → base для TZ-015 (discovery/registry/remote-exec/shared-ctx/metrics) и TZ-022 (sync).
- **TZ-AGENT-001**: IAgentPlatform, ILlm → reuse во всех слоях (society, planner, OS).
- **TZ-OBS-001**: ITelemetrySink → TZ-015 cluster metrics, TZ-020 self-metrics.
- **ADR-042**: ArchitectureIntelligence (L5/L6/L7) → TZ-020 architecture critic.
- **ADR-045/046/047/048/049/050/051/052**: порты и сервисы каждого ТЗ.

## 4. LAW Compliance (все ТЗ)
- **K1**: все порты в contracts.
- **K3**: composition wiring.
- **K5**: orchestrators coordinate, execution delegated to IAgentPlatform/IAgentPlatform;
  selective sharing default DENY (TZ-022); policy evolution suggests only (TZ-020).
- **K6**: узлы через порты (IEventBus/ICrdtGraph/ILlm/IAgentPlatform).
- **K8**: adapters/services НЕ импортируют kernel/runtime.

## 5. Implementation Order (recommended, после K5 go на каждый ТЗ)
1. TZ-015 (distributed runtime completion) — base для federation
2. TZ-016 (autonomous planner)
3. TZ-017 (memory evolution)
4. TZ-018 (world model)
5. TZ-019 (agent society)
6. TZ-020 (self improvement)
7. TZ-021 (marketplace)
8. TZ-022 (federated network)
9. TZ-023 (cognitive OS) — финальная интеграция

## 6. Validation
- Все design: ad-hoc verify 8/8 PASS, gate 14, akb-lint PASSED, no regressions.
- Code阶段 (после K5 go): каждый ТЗ +12 tests, suite target ~966 + 9×12 = ~1074.
