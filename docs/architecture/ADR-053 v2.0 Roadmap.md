## 1. Cognitive FSM (primary invariant, ADR-054 I-01/I-02)

```
        ┌──────────────────────────────────────────────────────────┐
        │                     EXECUTIVE CONTROLLER                    │
        │   sole transition authority (I-02); LLM-free enforcement   │
        └──────────────────────────────────────────────────────────┘
                              ↑ controls ↓
  Idle ─▶ Observe ─▶ Orient ─▶ Deliberate ─▶ Commit ─▶ Execute ─▶ Evaluate ─▶ Learn ─┐
   ▲                                                                                 │
   └─────────────────────────────────────────────────────────────────────────────────┘
```
- **system-1** (LLM-free, reactive): Idle→Observe→Orient→(rule)→Execute (I-09/I-16).
- **system-2** (deliberative): через Deliberate (Reasoning→Planning→Decision).
