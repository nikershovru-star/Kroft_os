# qa_102 — What is a confounder?

DOMAIN: causal
TYPE: FACTUAL
CONFIDENCE: high
PROVENANCE: paper:Causality
TTL: 365

QUESTION: What is a confounder?
ANSWER: A variable that influences both the presumed cause and the effect, creating a spurious link.
EXAMPLE: Wealth confounds education and health.
