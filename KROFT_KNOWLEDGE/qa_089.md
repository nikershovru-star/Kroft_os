# qa_089 — What is cross entropy?

DOMAIN: info-theory
TYPE: FACTUAL
CONFIDENCE: medium
PROVENANCE: paper:CrossEntropy
TTL: 365

QUESTION: What is cross entropy?
ANSWER: The average message length when using a wrong distribution to encode events from the true one; used as a loss.
EXAMPLE: Classification trains to minimize cross entropy between predictions and labels.
