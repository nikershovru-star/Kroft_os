# qa_004 — What is an embedding?

TYPE: FACTUAL
CONFIDENCE: high
PROVENANCE: paper:Attention
TTL: 365

QUESTION: What is an embedding?
ANSWER: A numeric vector representation of text (or other objects) in a multidimensional space where semantically similar items sit closer.
EXAMPLE: The query about memory may sit near the query about OS state.
