# qa_011 — What is dependency inversion?

TYPE: CONCEPTUAL
CONFIDENCE: high
PROVENANCE: clean-arch
TTL: 365

QUESTION: What is dependency inversion?
ANSWER: High-level modules should not depend on low-level ones; both depend on abstractions.
EXAMPLE: KnowledgeEngine depends on KnowledgeStore, not on JsonMemoryStore directly.
