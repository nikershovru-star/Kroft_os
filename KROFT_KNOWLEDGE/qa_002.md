# qa_002 — What is a process?

TYPE: FACTUAL
CONFIDENCE: high
PROVENANCE: textbook:OSTEP
TTL: 365

QUESTION: What is a process?
ANSWER: An executing instance of a program with its own address space, state, and resources.
EXAMPLE: Running the same binary twice yields two independent processes.
