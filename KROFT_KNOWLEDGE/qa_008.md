# qa_008 — What is virtual memory?

TYPE: FACTUAL
CONFIDENCE: high
PROVENANCE: textbook:OSTEP
TTL: 365

QUESTION: What is virtual memory?
ANSWER: An abstraction that gives each process its own address space backed by physical RAM and disk.
EXAMPLE: A process allocates memory without knowing the physical frame.
