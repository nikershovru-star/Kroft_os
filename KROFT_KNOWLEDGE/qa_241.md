# qa_241 — How to write a good commit?

DOMAIN: SE-practices
TYPE: PROCEDURAL
CONFIDENCE: high
PROVENANCE: se:practice
TTL: 180

QUESTION: How to write a good commit?
ANSWER: Make it atomic, name the files, and describe intent and why, not only what.
EXAMPLE: One fix per commit with a clear message.
