# qa_001 — What is an operating system?

TYPE: FACTUAL
CONFIDENCE: high
PROVENANCE: textbook:OSTEP
TTL: 365

QUESTION: What is an operating system?
ANSWER: A program that manages hardware resources and gives applications a standard interface to CPU, memory, files, devices, and other processes.
EXAMPLE: An app writes a file via a syscall; it does not drive the disk directly.
