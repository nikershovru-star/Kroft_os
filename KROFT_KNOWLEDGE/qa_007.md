# qa_007 — What is an interface?

TYPE: FACTUAL
CONFIDENCE: high
PROVENANCE: clean-arch
TTL: 365

QUESTION: What is an interface?
ANSWER: A contract defining how components interact without exposing implementation.
EXAMPLE: KnowledgeStore defines read/write/search; SQLite or JSON may implement it.
