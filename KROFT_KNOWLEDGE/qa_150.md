# qa_150 — What is entailment?

DOMAIN: linguistics
TYPE: CONCEPTUAL
CONFIDENCE: high
PROVENANCE: ling: discourse
TTL: 365

QUESTION: What is entailment?
ANSWER: When one sentence must be true if another is; a relation used in inference tasks.
EXAMPLE: A dog runs entails an animal moves.
