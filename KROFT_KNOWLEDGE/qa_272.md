# qa_272 — What is defense in depth?

DOMAIN: security
TYPE: CONCEPTUAL
CONFIDENCE: high
PROVENANCE: sec:basic
TTL: 365

QUESTION: What is defense in depth?
ANSWER: Layering independent controls so one failure does not breach the system.
EXAMPLE: Firewall plus auth plus audit.
