# qa_110 — How to use an A/B test for causation?

DOMAIN: causal
TYPE: PROCEDURAL
CONFIDENCE: high
PROVENANCE: paper:A-BTesting
TTL: 180

QUESTION: How to use an A/B test for causation?
ANSWER: Randomly assign users to variant A or B and compare outcomes; randomisation balances confounders.
EXAMPLE: Half the users see the new button; convert rates are compared.
