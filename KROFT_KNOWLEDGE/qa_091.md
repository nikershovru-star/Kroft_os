# qa_091 — What is a hypothesis?

DOMAIN: scientific-method
TYPE: FACTUAL
CONFIDENCE: high
PROVENANCE: phil:science

QUESTION: What is a hypothesis?
ANSWER: A testable proposed explanation; it must be falsifiable to be scientific.
EXAMPLE: Helium makes balloons rise is testable; it is a hypothesis.
