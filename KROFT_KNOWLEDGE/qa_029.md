# qa_029 — How to add a new adapter?

TYPE: PROCEDURAL
CONFIDENCE: high
PROVENANCE: clean-arch
TTL: 180

QUESTION: How to add a new adapter?
ANSWER: Implement the existing port, inject it at the composition root, never import it from kernel.
EXAMPLE: OllamaEmbeddingAdapter implements IEmbedding and is wired in build_kernel.
