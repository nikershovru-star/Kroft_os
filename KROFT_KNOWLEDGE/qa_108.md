# qa_108 — What is an instrumental variable?

DOMAIN: causal
TYPE: FACTUAL
CONFIDENCE: medium
PROVENANCE: paper:Instrument
TTL: 365

QUESTION: What is an instrumental variable?
ANSWER: A variable that affects the outcome only through the cause; used to estimate causation without randomisation.
EXAMPLE: Rainfall affects crop sales via harvest, not demand.
