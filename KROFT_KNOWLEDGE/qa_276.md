# qa_276 — What is encryption?

DOMAIN: security
TYPE: FACTUAL
CONFIDENCE: medium
PROVENANCE: sec:basic
TTL: 365

QUESTION: What is encryption?
ANSWER: Transforming data so only key holders can read it; at rest and in transit.
EXAMPLE: A file is unreadable without the key.
