# qa_112 — What is a syllogism?

DOMAIN: critical-thinking
TYPE: FACTUAL
CONFIDENCE: high
PROVENANCE: phil:logic
TTL: 365

QUESTION: What is a syllogism?
ANSWER: A three part inference with two premises and a conclusion; valid if structure preserves truth.
EXAMPLE: All men are mortal; Socrates is a man; therefore mortal.
