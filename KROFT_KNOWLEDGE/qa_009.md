# qa_009 — What is graceful degradation?

TYPE: FACTUAL
CONFIDENCE: high
PROVENANCE: sre:google
TTL: 365

QUESTION: What is graceful degradation?
ANSWER: When part of a system fails it keeps working in a reduced mode instead of crashing.
EXAMPLE: If vector search fails, fall back to keyword search with lower confidence.
