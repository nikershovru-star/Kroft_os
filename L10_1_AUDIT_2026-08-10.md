Process N+1 CONTROL (TMP_CONTROL = copy BASELINE, NO loop run):
  goal = "what is speech and language processing?"
  episodes пусты → retrieval НЕ находит FACT_B → plan N+1 НЕ grounded в jurafsky

CRITERION: Treatment.plan references FACT_B node, Control.plan does NOT.

## 7. Autosave / TMP isolation (точный вывод)

- `KroftApp.__init__` (run_kroft.py:400-401): `self._save_knowledge()` — **БЕЗУСЛОВНЫЙ autosave**.
- Path = `cfg.knowledge_snapshot` (через `self._snapshot_store`, run_kroft.py:239).
- Constructor МОЖЕТ изменить control-файл (пишет restore+seed state).
- Restore НЕ вызывает save (кроме init-autosave).
- **Решение:** control/treatment = отдельные файлы; control НЕ запускает loop (иначе добавит episode);
  treatment запускает loop → autosave пишет в treatment-файл (control не трогается).
